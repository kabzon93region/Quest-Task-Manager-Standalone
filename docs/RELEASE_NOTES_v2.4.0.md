# QTaskMgr Standalone v2.4.0

## ADB-уведомление с RemoteInput

Настройка pairing и подключения прямо из шторки уведомлений — без переключения с экрана Wireless debugging.

- **Этап 1 (Pairing)**: уведомление с полем ввода "порт код" — вводите данные и нажимаете "Pair", оставаясь на экране настроек.
- **Этап 2 (Connect)**: уведомление обновляется — вводите debug-порт и нажимаете "Подключить".
- При успешном подключении уведомление автоматически скрывается.

## Адаптивная разметка

- Фильтры и кнопки закрытия сворачиваются в 2 строки в портретном режиме (FlexboxLayout).
- Табы прокручиваются горизонтально на узких экранах.
- Настройки: кнопки GitHub/Donate и Connect/Disconnect адаптируются к ширине экрана.

## Установка

APK: `dist/QTaskMgr-Standalone-v2.4.0-release.apk`

Совместим с обычным **QTaskMgr** (`com.quest3.taskmanager`) — можно ставить оба.
